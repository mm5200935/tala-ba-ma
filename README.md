# ✨ طلا با ما | Tala Ba Ma

### پلتفرم خرید و فروش آنلاین طلای ۱۸ عیار

**طلا با ما** یک رابط کاربری مدرن و جذاب برای پلتفرم خرید و فروش آنلاین طلای ۱۸ عیار است که با هدف ارائه تجربه‌ای ساده، سریع و امن در معاملات آنلاین طلا طراحی شده است.

این پروژه با استفاده از HTML5، CSS3 و JavaScript پیاده‌سازی شده و دارای طراحی واکنش‌گرا (Responsive) برای نمایش صحیح در موبایل، تبلت و دسکتاپ است.

---

## 🚀 ویژگی‌های پروژه

- 🎨 طراحی مدرن و لوکس با تم مشکی و طلایی
- 📈 نمایش قیمت طلای ۱۸ عیار
- 📊 نمودارهای تغییرات قیمت طلا با Chart.js
- ⏱️ به‌روزرسانی خودکار اطلاعات قیمت (در حالت نمایشی)

- 📊 بخش نمایش آمار و ارقام
- ❓ بخش سوالات متداول (FAQ)
- 💬 پشتیبانی ۲۴ ساعته از طریق تلگرام
- 📱 طراحی کاملاً Responsive
- ✨ انیمیشن‌ها و جلوه‌های بصری جذاب
- 🌐 پشتیبانی کامل از زبان فارسی و چیدمان RTL

## ⚙️ نحوه اجرا

برای اجرای پروژه نیازی به نصب وابستگی یا راه‌اندازی سرور خاصی نیست.

1. پروژه را دانلود یا Clone کنید:

```bash
git clone https://github.com/USERNAME/tala-ba-ma.git
```

2. وارد پوشه پروژه شوید:

```bash
cd tala-ba-ma
```

3. فایل `index.html` را با مرورگر باز کنید.

همچنین می‌توانید از افزونه Live Server در Visual Studio Code برای اجرای پروژه استفاده کنید.
